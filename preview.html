How to run locally

In the repository root, run node preview.cjs with Node.js 18 or later, then open http://127.0.0.1:3000/preview.html. No package installation is needed. Keep the terminal open; press Ctrl+C to stop. If port 3000 is occupied, use node preview.cjs 3001 and the printed URL.

This read-only local server lists uncommitted and Git-ignored files. Hidden paths, dependency/test directories and symbolic links are excluded. Markdown uses the existing reader; scripts, JSON and infrastructure code use the syntax-highlighted code reader. Images, PDFs and other supported media open directly. Unsupported types are listed as not previewable. JSON contents are now served: keep credentials and sensitive runtime configuration outside visible paths. Refresh after adding or deleting files. Document links and heading anchors update the address bar and support browser Back/Forward. Other links navigate outside the preview frame; links to new tabs and modifier-clicks keep their normal behavior. The existing Markdown reader is embedded unchanged; its external CDN dependencies still require internet access.

Double-clicking this page, or using a generic static server, cannot provide the local directory API. The original static home and reader do not depend on this preview service.
